## 👋 About Me

WordPress plugin developer based in **Dhaka, Bangladesh** 🇧🇩

For the last few years my focus has been **WordPress plugin customization** — building on and extending **WooCommerce**, **Dokan** multivendor marketplaces, **Stripe** and other payment gateways, and custom **WordPress themes**. Before that I worked across the classic web stack with **PHP, Laravel, MySQL, Vue, JavaScript** and **Bootstrap**.

I'm genuinely curious about new technology and the science behind how things work — always learning, always shipping.

- 💼 **Focus:** WordPress plugin development — WooCommerce, multivendor (Dokan), Stripe payments, custom themes
- 🌱 **Learning:** advanced WordPress plugin architecture, PHP / Laravel, and modern JavaScript
